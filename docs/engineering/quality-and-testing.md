# Quality targets and evidence plan

Numeric limits below are selected engineering acceptance targets, not guarantees or measurements. They replace vague “fast/accurate” requirements. Changing them requires reviewed scope change. A successful fixture checks mechanics; it cannot certify the actual native thread, Drive connection, owned writer, full corpus or educational validity.

| ID | Area | Required criterion | Evidence |
|---|---|---|---|
| QT01 | Integrity | Zero wrong-course writes, conflicting overwrite acceptance, duplicate accepted learner attempts, or fabricated completion in the complete adversarial test set. | Fixture/property tests + real owner integration. Zero observed failures is not a universal proof. |
| QT02 | All-lecture preparation | 100% of the frozen release inventory has a valid source disposition; no recoverable present material left unprocessed at full release. Every applicable slide link is reviewed or explicitly unresolved with evidence; nonrecoverable missing originals remain visible. | Freeze current inventory at acceptance; retain 37 reported units as history not a permanent hard-coded denominator. Report counts for each status. Unresolved recoverable linking prevents full completion without explicit scope decision. |
| QT03 | Source fidelity | No known incorrect reviewed link. Manual correction must persist across every regeneration and source revision scenario. | Reviewed held-out cases from every configured course plus replay checks; correctness evaluated separately from volume. |
| QT04 | Alignment suggestion quality | At least 95% precision among proposed high-confidence links on at least 100 adjudicated cases spanning all five courses, including skips/repeats; report coverage and a binomial confidence interval. Suggestions remain suggestions. | Held-out sources; unseen repeated/partial transcript cases; failures do not lower the target automatically or justify marking suggested links confirmed. |
| QT05 | Timing and playback | On unambiguous labeled spans, p95 absolute boundary error <= 2 seconds; player seek lands within 0.5 seconds after seeked on supported media, tested separately from link accuracy. | Real source labels/codec/device tests; compressed media timing exceptions are documented, not relabeled exact. |
| QT06 | UI responsiveness | Local loaded-state interactions p95 <= 150 ms; local durable-submit acknowledgment p95 <= 500 ms after storage commit; source warm navigation p95 <= 1 s. | 100 repetitions on documented reference PC/browser. Network upload, Drive sync and AI completion measured separately, no fabricated end-to-end SLA. |
| QT07 | Dispatch delay | Once full valid bytes are readable locally, admission within two configured scan periods when not resource-blocked. Queued native wait, provider time and output sync are separately visible. | Deterministic clock fixtures then actual Drive/PC observations; scans default 5 s active/15 s idle. |
| QT08 | Tutor/assessment | No known critical false grading, answer leakage or unsupported diagnosis in the release set. Target >=95% reviewer agreement on observable criteria, <=5% false rejection of valid alternatives, and explicit uncertainty on ambiguous/recognition cases. | At least 100 held-out judgments spanning all courses and task types; report denominators/CI, assistance and reviewed-label disagreements. Human/model consensus alone is not ground truth. |
| QT09 | Learning claims | Quick-answer exchanges create no new performance record; unobserved is never failure. No learned/retention/transfer percentage claim without its own evaluated evidence. | Record/output tests and representative real tutoring; later unaided performance is observed separately, not required to prove a fake guaranteed improvement. |
| QT10 | Accessibility/themes | All relevant 24 global UI cases pass in both themes, with keyboard, focus, 200% text, narrow reflow, reduced motion and actual chosen devices. Original scientific colors unchanged. | Playwright and axe-core plus manual keyboard/screen-reader checks; automated zero findings is not WCAG certification. |
| QT11 | Recovery | Every submitted input acknowledged by Brain remains recoverable after injected interruption; uncertain native completion reconciles before retry; no loss from failed view generation. | Fault injection and actual same-user restart/reconnect/backup tests. Device-only draft is labeled with browser-storage limits. |
| QT12 | Costs and resources | No unapproved separately billed calls or public PC endpoint. One native turn and one background processing unit by default; no model calls while idle. | Admission/config tests plus usage/log review. Existing subscription allowance and current measured cost remain external facts, not inferred from local counters. |
| QT13 | Device support | Support current stable Windows Edge/Chrome plus mobile Safari and Chrome UI; exact versions recorded at acceptance. Tablet/narrow layouts share actions. | Run actual available target hardware sessions; mark missing platform evidence BLOCKED for that platform, not globally verified via viewport emulation. |

## Test layers
Retain the existing 192 story cases, 24 global UI cases and 76 workflow cases unchanged as intended behavior. Add runtime test IDs when implemented, not fictional filenames marked PASS now. Build tests one scenario at a time. Use unit/property tests for IDs/bounds/transitions, contract fixtures for adapters, OS-backed isolated writer tests for persistence, actual browser tests for UI, and separately authorized native/Drive/device proofs.

Compare baseline rules/native search versus the selected probabilistic step on matched versioned examples. Include correct alternative explanations, hidden-answer exposure, unobservable criteria, recognition ambiguity, stale sources and deliberate grading errors. Keep adjudication and test cases separate from implementation prompts where feasible. Log output quality, abstention, latency, cost and human correction separately. No universal leaderboard or automatic model replacement from synthetic examples.

Before full release, every active requirement has current applicable evidence; unresolved critical identity/privacy/write failures block release. A known missing original recording is an explicit material fact, not manufactured content. Bounded tests never reduce all-lecture scope.
