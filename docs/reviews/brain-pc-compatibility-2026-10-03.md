## Explicit corrections to 0.5.0
The provisional `learning/concepts/revisions/`, `learning/gaps/events/`, `learning/app-links/`
and canonical `learning/review/` stores are **withdrawn as default destinations**. They were
uninstalled proposals, so this is a documentation correction, not a data migration. Existing
`learning/skills.yaml`, `learning/question-families.yaml`, BE 505's question index, attempts
and approved shared mappings remain their owners. No independently editable second gradebook.

Full-submission evidence now uses the proposed `.agent/course-learning/runs/<run-id>/turns/`
child identified in P06. Question plus learner response are captured immutably before inference;
assistant replies are separate immutable objects written later. A generated conversation view
joins them. This preserves full visible content without changing a snapshot already hashed
into an attempt or adding unknown records to `learning/attempts/`.

Genuine missing/incorrect reasoning stays in existing observation fields. Rich diagnostic
hypotheses can be staged operational analysis, clearly labeled not an assessment; important
changes to a recorded judgment use the existing connected assessment-revision chain. A novel
semantic field requires a reviewed extension to its current owner, not a hidden ledger.
