Create the separate application checkout, resolve the chosen stable dependency versions, and implement
the reusable source-first light/dark shell, immutable synthetic input capture and local journal.

Application `apps/web`, `apps/brain` fixture-only modules, shared contracts, fixture tests, local-only
Storybook and relevant specs/check configuration. Reuse actual Seed infrastructure; preserve its

## Not included

No real Drive reads/writes, academic file copy, installed writer import, native process dispatch,
transcription/model download, OAuth grant, runtime changes, resident startup task, public host, repository
upload or canonical attempt. Fake data/results stay visibly synthetic and cannot satisfy live gates.

## Acceptance to implement

A private synthetic course opens with source-first layout, original slide colors and Light/Dark/System;
controls work using keyboard and reduced motion. A submitted answer is frozen once, survives a simulated
model failure, and a separate later message cannot change its digest. Same input double-submit does not
create a second learner event; changed bytes under the same identity conflict. The journal survives
restart without duplicate publication claims. Theme/panel changes preserve a draft and media instance.
Browser tests cover these actual controls, not only snapshots. Record commands, environments, skips,
failures and test identities outside the specification folder.
