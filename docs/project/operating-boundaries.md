# Current operating boundaries

The always-on Brain PC is the processing and authoritative publication host. User-facing devices
can upload originals through existing ownership and submit app commands/drafts; they should not
directly rewrite canonical learner, concept or review records. Existing manual/agent writers must
join the same publication contract or be recognized as concurrent conflict risks.

One normal supervisor observes/reconciles Drive and runs eligible workflows. Named workers have
bounded trusted instructions, roots, permissions, budget, dependencies and output shape. This is
not an open-ended LLM allowed to change its own instructions until all questions disappear.
No model calls at idle. Waiting learner input/review/source/quota blocks only its dependent jobs.

Task files, sources and quoted agent instructions are untrusted input, not permission to execute
commands, expose credentials, change schedules or expand write scope. Existing schemas and IDs
remain authoritative; proposed metadata/status enums stay in the app adapter until compatible
schema updates are separately reviewed. Full capture includes submitted visible Q/A, not secret
keys, unrelated transcripts, keystrokes or hidden chain-of-thought.

All grades, submissions, deadlines, Calendar/Tasks/Gmail/LMS and shared-learning publication retain
their current owners. Native reasoning activity is distinct from staging and canonical saves.
The existing source-refresh can be a feed/owner, not a second job raced by the new watcher.
Physical source hashing must actually run; publication consistency is not proof of source freshness.
Windows runtime-specific locks cannot silently move to another interpreter/service account.

Privacy permissions still apply to provider processing, raw voice and remote clients. No new paid
inference, public tunnel, copied browser auth, provider installation or automatically generated
scope approval. Service start/restart, read/write grants and workflow policies must be approved
before activation. No live job or daemon is started by this specification work.
