# Memory/workflow fit review — 0.7.0

The user requested a per-memory and per-workflow existing/modify/build decision. This review uses
P05, the visible partial P06 and all 12 v0.6 workflow contracts, not a new live audit. It preserves
the latest ownership corrections and all accepted product scope. No unobserved tool or service is
classified operational because a prompt, CLI help entry or JSON schema exists.

## Findings resolved in the design

- Every memory item M01-M15 has current status, existing/proposed location, single authority,
  modification/build scope, rationale, consumer workflows and proposed acceptance.
- Every workflow WF00-WF11 has current-system status, smallest change, memory dependencies,
  trigger/read/write/success/block/no-go contract and existing owner.
- Alignment annotations cannot be purely disposable exports: genuinely new reviewed intervals
  need an explicitly approved record under the existing source-link owner, not a second graph.
- All submitted learner input is captured, while canonical assessment waits when family/rubric
  coverage is insufficient. Waiting is not a fabricated learner failure.
- Concept projections preserve endpoint types and cannot reinterpret question containment as
  stronger concept/prerequisite hierarchy. Bounded traversal is distinct from blanket acyclicity.
- Gap views derive from effective observations with counterevidence; pending causes remain
  operational proposals. Review scheduling has its own operational event history, not competence.
- Structured views are deterministic; generated prose is source-linked but not asserted to be
  reproducible word for word. Context invalidation cannot become automatic regrading of history.
- Durable response sidecars must be excluded from generic run cleanup; schema-approved locator
  strings alone do not verify them. The full-turn verifier remains required new code.
- Existing source updater caps and locks remain in force; draining the larger backlog requires
  its owner-approved continuation, not duplicate cron or shadow source publication.
